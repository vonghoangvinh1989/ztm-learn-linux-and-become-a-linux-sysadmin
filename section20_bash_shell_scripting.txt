1) Bash Aliases
    a) Alias commands
        alias --> list all current alias commands

        \ls --> run the original 'ls' command, not alias ls command 

        alias c="clear" --> create 'c' is the alias of 'clear' command 
            (to make the alias permanent, we have to put it in ~/.bash_profile, ~/.bashrc)

        date +%F\ %T --> command to show date and time with format "2026-11-01 11:16:30"

        alias now="date +%F\ %T" --> create 'now' is the alias of date command 
        
        source ~/.bashrc --> read and execute commands from a file in the current shell environment (use in case
    of create new alias in .bashrc and need current shell read again)

        unalias now --> to remove the alias 'now'

    b) Useful aliases
        alias server1="ssh -p 2234 user1@79.1.3.5"

        alias ports="netstat -tupan"

        alias root="sudo su"

        alias update="sudo apt update && sudo apt dist-upgrade -y && sudo apt clean"

        alias lt="ls -hSF --size -1"

3) The Bash Shebang and comments
    Note: shebang (#!): indicate which program to run as intepreter with the script file 
    
    #!/bin/bash --> shebang for bash script
   
    #!/usr/bin/python3 --> shebang for python3 script

    which python3 --> search for location of python3 

    # --> use for comments in script

4) Running scripts
    a) first way to run the script is adding permission to the file and run with absolute path or relative path such as ./my_script.sh or
/home/vonghoangvinh/scripts/first_script.sh 

    b) second way to run the script is writing the name of the program or intepreter and the script name
        bash first_script.sh --> run bash script with 'bash' 
        python3 myscript1 --> run python script with 'python3'

        Note: in this way, script does not need to have execute permission to run and it also overwrites the 
    shebang directive

        chmod -x first_script.sh --> remove running permission 
        bash first_script --> still running

    c) third way to run the script is using 'source' command 
        source first_script.sh --> run script with source, but the different is the script will be 
    running in the current shell (if we run: ./first_script.sh, the script will be run in the new shell or subshell)

        . first_script.sh --> is the same as 'source first_script.sh' 

Note: the most common one to run is the first method 

5) Variables in Bash
    a) create variables
        os=Linux --> create variable 'os' with value 'Linux', not allow to have space before or after '='

        distro="MX Linux" --> variable contains string, put it in double quotes 

        age=30 --> variable contains number integer

    b) some illegal variable names
        4you=True --> this illegal variable name
            (command not found)
        a.b=100 --> illegal
        Anne@ --> illegal 
        Anne@Marry=d --> illegal
    
    c) some legal variable names
        you4=False --> legal variable name 
        server_name="Apache 2.4" --> legal variable name 
        A=34 --> legal 

    d) viewing values of variables
        echo $age --> access the value of variable 'age' using $, echo for printing

        echo "I'm learning $os and I'm $age old." --> $os and $age will be replaced by the value 
    or variable 'os' and 'age', we have to use double quotes to see the value

        echo '$os something $age' --> when using single quote, the name of variable is not replaced 
    by its value, here the result is '$os something $age'

        echo "The value of \$os is $os" --> using backslash symbol to escape (cancel) the special
    meaning of '$', result is 'The value of $os is Linux'

    e) get values of variables and assign to other variables
        distro="Ubuntu"
        my_distro="$os $distro" --> take values of other variable to assign variable
        echo $my_distro --> will show 'Linux Ubuntu'

    f) search for variable in current shell
        set --> to display all shell variables and functions

        set | grep distro --> search for distro Variables
            distro=Ubuntu
            my_distro='Linux Ubuntu'

    g) remove variable with 'unset'
        echo $distro
        unset distro
        echo $distro

    h) some environment variables
        echo $PATH 
        echo $USER
        echo $HOME
        echo $HISTSIZE

    i) create constants
        declare -r logdir="/var/log"
        ls $logdir --> will list content of '/var/log'
        logdir="abc" --> show 'readonly' error since we already set the variable is constant 

        unset logdir --> cannot unset also since it will be readonly variable 

    j) create file_stat.sh with content and assign permissions and run
