1) Bash Aliases
    a) Alias commands
        alias --> list all current alias commands

        \ls --> run the original 'ls' command, not alias ls command 

        alias c="clear" --> create 'c' is the alias of 'clear' command 
            (to make the alias permanent, we have to put it in ~/.bash_profile, ~/.bashrc)

        date +%F\ %T --> command to show date and time with format "2026-11-01 11:16:30"

        alias now="date +%F\ %T" --> create 'now' is the alias of date command 
        
        source ~/.bashrc --> read and execute commands from a file in the current shell environment (use in case
    of create new alias in .bashrc and need current shell read again)

        unalias now --> to remove the alias 'now'

    b) Useful aliases
        alias server1="ssh -p 2234 user1@79.1.3.5"

        alias ports="netstat -tupan"

        alias root="sudo su"

        alias update="sudo apt update && sudo apt dist-upgrade -y && sudo apt clean"

        alias lt="ls -hSF --size -1"

4) Running scripts
    a) first way to run the script is adding permission to the file and run with absolute path or relative path such as ./my_script.sh or
/home/vonghoangvinh/scripts/first_script.sh 

    b) second way to run the script is writing the name of the program or intepreter and the script name
        bash first_script.sh --> run bash script with 'bash' 
        python3 myscript1 --> run python script with 'python3'

        Note: in this way, script does not need to have execute permission to run and it also overwrites the 
    shebang directive

        chmod -x first_script.sh --> remove running permission 
        bash first_script --> still running

    c) third way to run the script is using 'source' command 
        source first_script.sh --> run script with source, but the different is the script will be 
    running in the current shell (if we run: ./first_script.sh, the script will be run in the new shell or subshell)

        . first_script.sh --> is the same as 'source first_script.sh' 

Note: the most common one to run is the first method

6) Environment Variables 
    a) environment variables
        + define for the current shell, inherited by any child shells or processes
        + used to pass info to processes that are spawned from the current shell 
        + displayed using env or printenv

        for example:
            echo $PATH
            echo $HOME

            env --> list all environment variables
            env | grep USER --> search 'user'
            env | grep SHELL --> search 'shell'

            printenv --> list environment variables, same as 'env'
            printenv HOME --> show the value of environment variable "HOME"
            printenv SHELL --> show the value of SHELL such as /bin/bash

            printenv SHELL PWD LC_TIME --> pass multiple variables to printenv to print values 
    b) shell variables 
        + contained exclusively within the shell in which they were set or defined 
        + display using set

        abc=123
        env | grep abc --> not found any because this variable is shell variable 
        set | grep abc --> found it 
        
        set -o posix --> run set in posix mode and will not print the shell functions with 'set' command 
        set --> now it will display only environment and shell variables 

    c) configuration file 
        + user configuration files: ~/.bashrc
            vim ~/.bashrc 
            export PATH=$PATH:~/scripts --> add to the end of the file

            source ~/.bashrc --> load in the current shell
            echo $PATH --> now we can see the home/vinhvong/scripts inside the $path, and we can run 
        directly script files inside of $PATH location 

        + system-wide configuration files: /etc/bash.bashrc and /etc/profile 
            cat /etc/environment --> file contains PATH system wide

8) Special Variables and Positional Arguments
    ./script.sh filename1 dir1 10.0.0.1

    $0 is the name of the script itself (script.sh)
    $1 is the first positional argument (filename1)
    $2 is the second positional argument (dir1)
    $3 is the last argument of the script (10.0.0.1)
    $9 would be the ninth argument and ${10} the tenth

    $# is the number of the positional arguments 
    "$*" is a string representation of all positional arguments: $1, $2, $3...
    $? is the most recent foreground command exit status 

    For example: 
        ./arguments.sh linux windows mac 10
            $0 is ./arguments.sh
            $1 is linux
            $2 is windows
            $3 is mac
            $* is linux windows mac 10
            $# is 4

9) If, elif and else statements
    a) Syntax of if statements

        if [ some_condition_is_true ] --> need to have white space before and after bracket
        then 
            // execute this code 
        elif [some_other_condition_is_true ]
        then 
            // execute this code 
        else 
            // execute this code 
        fi --> delimiter entire if statements 

    b) Practical example
        vim display.sh --> create display.sh script to display regular file
            
            #!/bin/bash
            if [[ -f "$1" ]] # testing condition -f means file exists and is a regular file
            then
                echo "The argument is a file, displaying its contents..."
                sleep 1
                cat $1
            elif [[ -d "$1" ]] # testing condition -d means file exists and is a direcotry
            then
                echo "The argument is a directory, running ls -l..."
                sleep 1
                ls -l $1
            else
                echo "The argument ($1) is neither a file nor a directory."
            fi

        Note:
            + double quotes bracket is new syntax and much safer
            + vim: yl --> copy 1 character 
                p: paste after cursor 
                P: paste before cursor 
                x: delete 1 character 
                xp: swap two align characters
            + man test --> view help about testing conditions

10) Testing conditions for numbers 
        vim age.sh 

            #!/bin/bash
            read -p "Enter your age: " age

            if [[ "$age" -lt 18 ]] --> -lt: less than
            then
                echo "You are minor!"
            elif [[ "$age" -eq 18 ]] --> -eq: equal
            then
                echo "Congratulations, you've just become major!"
