1) DPKG (Debian and Ubuntu Based Distros)
    a) view info of deb file
        sudo dpkg --info google_chrome.deb --> view info of file 'deb'

    b) install deb file
        sudo dpkg -i google_chrome.deb --> install 'google_chrome.deb'

    c) view all installed packages
        sudo dpkg --get-selections --> get all installed packages on the system

    d) check version of specify package using dpkg-query with option -l
        dpkg-query -l | grep chrome --> get version of chrome package using dpkg-query and filter 
            ii: mean installed
    
    e) list all files related to a package
        dpkg -L google-chrome-stable --> list all the files installed on the system from the package 'google-chrome-stable'
    
    f) how to search a file that belong to which package
        which -a ls --> give result ''/usr/bin/ls', '/bin/ls'
        dpkg -S /usr/bin/ls --> what package a specific file belong to, using S option, here give the 
result 'coreutils-from-uutils: /usr/bin/ls'
        dpkg -L coreutils-from-uutils --> list all files from the package 'coreutils-from-uutils'

    g) remove a package using dpkg
        sudo dpkg -r google-chrome-stable --> delete package 'google-chrome-stable' but not remove configurations 
        sudo dpkg -P google-chrome-stable --> delete package and also remove configurations 

    h) other commands related to dpkg
        sudo dpkg -s google-chrome-stable --> check status of package 'google-chrome-stable'
        sudo dpkg -l --> list all packages 
        sudo dpkg -l | grep google-chrome-stable --> filter with 'google-chrome-stable'

2) Using APT (Advanced Package Tool)
    a) update the index of respository and get the lastest update
        sudo apt update --> pull the latest changes from apt respository (update the index)

    b) install package
        sudo apt install apache2 --> install apache2

    c) install multiple packages
        sudo apt install gparted vlc --> install multiple package in one single command 

    d) install a specific '.deb' file using apt
        sudo apt install home/vonghoangvinh/Downloads/google-chrome-stable.deb --> install deb with apt, it will call 'dpkg'
behind the scene (always provide the full path when install an application from a dev file using apt)

    e) get available upgrade list
        sudo apt list --upgradable --> get a list of all packages that can be upgraded 

    f) upgrade whole system
        sudo apt full-upgrade --> update system as a whole (apt full-upgrade -y: assume 'yes' if being asked)

    g) remove a package
        sudo apt remove apache2 --> remove an installed package, here is 'apache2' (it will uninstall the package, but can 
leave some configuration behind)

    h) remove a package and its configuration
        sudo apt purge apache2 --> using 'purge' will uninstalled and also remove all configuration files 

    i) remove unneeded dependencies after remove package
        sudo apt autoremove --> to remove unneeded dependencies

    j) check and clean cache of installed package
        ls /var/cache/apt/archives --> store downloaded .deb package files that apt uses to install software
        du -sh /var/cache/apt/archives --> check date usage of this directory
        sudo apt clean --> remove everything of that directory except the 'lock file'

    k) get available / installed packages
        sudo apt list --> get all available or installed packages
        sudo apt list | grep postfix --> find an available package such as 'postfix' mail server

    l) find a package via package description, we can use apt search
        apt search 'transparent proxy' --> search package with description 'transparent proxy'

    m) get all installed packages in the system 
        sudo apt list --installed --> get all installed packages

    n) view detail info of a package
        sudo apt show apache2 --> view detail info of apache2

3) Compiling C Programs 
    Source compilation guide 
        + install prerequisites: gcc, g++, make 
            sudo apt update && sudo apt install build-essential
        + download the source file 
        + check the integrity of tarball (hash)
        + extract the archive and move into the resulting directory 
        + run: ./configure --help and set required compilation options 
        + run: make 
        + run: make install 

    sudo apt update && sudo apt install build-essential --> update and install needed tools 

    sudo vim hello.c --> create a 'c' application and try to compile it 
        #include <stdio.h>
        
        int main() {
            printf("Hello, world!\n");
            return 0;
        }

    gcc hello.c -o hello --> compile code in hello.c into program name 'hello' (binary file)
    ./hello --> run the binary file 

4) Compiling Software from Source Code: Lab ProFTPD
    a) Install step by step 
        wget -c ftp://ftp.proftpd.org/distrib/source/proftpd-1.3.10rc4.tar.gz --> download the source code 

        sha256sum proftpd-1.3.10rc4.tar.gz --> calculate sha256 and check with the website 

        tar -xzvf proftpd-1.3.10rc4.tar.gz --> extract the source code file 

        cd ./proftpd-1.3.10rc4 --> go inside the directory 

        ls ./src --> source code of the server 

        ls -l configure --> 'configure' file check the requirements and dependencies of the program are satisfied 

        ./configure --help | less --> view configuration info 

        ./configure --prefix=/opt/proftpd  --> configure with option --prefix to install in /opt/, check all requirements 
    and dependencies, generate a file called 'Makefile'

        make --> build your application with make 

        sudo make install --> install the app, this will create the directory where the software will be installed 

        cd /opt/proftpd --> go the directory what we just installed 
        cd ./sbin --> go to sbin 

        sudo ./proftpd & --> run in background proftpd 

        pgrep -l proftpd --> check status of proftpd 

    b) Install in short way 
        ./configure --prefix=/opt/proftpd1 && make && sudo make install
