1) terminals, consoles, shells and commands
	a) shortcut to open terminal: Ctrl + Alt + T 
    b) shell: program get commands from user keyboard and pass to system kernel operating system to execute
    c) Useful commands
        ip a --> view the ip address of computer
    d) console: like terminal but without gui (ctrl + alt + [f1..f8]) or text only
        
2) linux command structure
    a) command: ping -c 1 8.8.8.8 --> check the internet is working with ping dns google
        Example: ping -c 127.0.0.1
            ping: command name
            c: command option
            1: option value
            127.0.0.1: command argument

    b) command: ls --all and ls -a are the same, ls -a can show hidden files
    c) command show the file system and disk space used
        df -h
        df -hia
        
3) getting help, man pages
    a) man pages
        example: man ls
            h --> showing help, press 'q' to quit
            ctrl + f / space --> forward one window
            ctrl + b --> backward one window
            g --> go to the beginning of the page
            G --> go to the end of the page

            /search_term --> to search the word, for example '/sort' to search the word 'sort' (search from the beginning of the page)
                n -> go to the next match
                N -> go to the backward match

            ?search_term --> to search the term, but start at the end of the page (N)

    b) To check a command is an executable files on the disk or build-in shell, using the 'type' command 
        type df --> (usr/bin/df), so that's mean it's executable file
            (to see the help of these command use man command: 'man df')
        type cd --> cd is a shell buildin
            (to see the help of these command use help command: 'help cd')
        *note: there's one help available to both type is 'command name --help', cd --help, ls --help

    c) command ifconfig to view ip and mac address
        ifconfig

    d) how to search key term in all man pages
        man -k 'copy files' --> search term 'copy files' in man pages
        man -k ifconfig / man -k uname

        alternate command: apropos ifconfig --> same as man -k

4) keyboard shortcuts
    ctrl + l --> clear the screen
    ctrl + d --> close the bash shell
    ctrl + a --> move the cursor to the beginning of the command line
    ctrl + e --> move the cursor to the end of the command line
    ctrl + u --> delete all characters before the cursor and adding them to the clipboard
    ctrl + c --> to stop the process
    ctrl + z --> suspend the process and put it in background
        jobs --> list background jobs
        bg %1 --> to continue running in 
        
5) the bash history
    a) cat .bash_history --> file stored history commands
    b) echo $HISTFILESIZE --> the number of commands stored in .bash_history
    c) echo $HISTSIZE --> the number of commands kept in memory during shell session
    d) To see the history of commands, using 'history'
            history --> view history commands
            !959 --> rerun command in history with !
            !! --> rerun the last command
            !-7 --> rerun the last 7 command
            !ping --> run the last ping command (search and run --> very dangerous)
            !ping:p --> printing the command, not running it (useful to check before running)
            history -d 970 --> delete command at line 970
            history -c --> clear content of history file

    e) Walkthrough command history
            ctrl + p / Up Arrow --> go to previous command
            ctrl + n / down arrow --> go to the next 
            ctrl + r --> to search the command (type the keyword), when found press enter to run
                    --> search but do not want to run, ctrl + g to exit

    Note: 
    + history --> HISTSIZE
    + ~/.bash_history --> HISTFILESIZE
    + when you type command and check ~/.bash_history, it does not store that command, but when you
log out and login again, check .bash_history, it will be there

6) running commands without leaving a trace
    a) put a space in front of command will not leave a trace in history
        for example: ' ls -l' or ' who'

    b) echo $HISTCONTROL --> check this variable, if it's 'ignoreboth' that means ignore white space in front
and ignore duplicate, ignoreboth = ignoredups + ignorespace, meaning 'not saving in history 
when have space in front and commands are duplicate'

7) recoding the date and time for each line in history
    HISTTIMEFORMAT="%d/%m/% %T "

8) root vs non-priviledge users
    a) sudo su --> enter user password (su: substitute user), user must be in sudo group,
    still in user home directory, open a root shell
        note: command 'id' show user's identity such as user id, primary group id and groups the user belongs to
    
    b) sudo su - --> enter user password, root working enviroment activated, go to root home directory, new shell with #
    
    c) sudo command --> run a command with root priviledges
        for example: sudo groupadd myadmin

    d) su --> enter root password, become temporary root in this terminal
Note:
    + sudo -v --> update the cached credentials without a command
    + sudo -k --> invalidate the user's cached credentials, after that need to type the password

    + / --> this is root directory
    + /root --> this root home directory
    + /home --> this is home directory of users
