4) the ls command in depth
    a) ls -1 /etc --> display in one line with '-1'
    
    b) ls -l /etc --> display long listing with '-l'
        drwxr-xr-x  2 root                 root                  4096 Jul 22 20:38 vim
        lrwxrwxrwx  1 root                 root                    23 Jun  4  2025 vtrgb -> /etc/alternatives/vtrgb
        -rw-r--r--  1 root                 root                  4942 Oct  2  2025 wgetrc
  
        'd' in front --> directory
        'l' in front --> symbolic link, like a shortcut
        '-' in front --> file
        'rwxrwxrwx' --> indicate permission of "owner, group owner and others"
        '2' --> the number of hard links
        'root root' --> owner and group owner
        '4096" --> size
        'Jul 22 20:38 vim' --> modification time and file name

    c) ls -ld /etc --> display long listing with only directory, not list the content of directory '-d'
    
    d) ls -lh /etc --> show file size in readable format
    
    e) ls -la ~ --> show all, includes hidden files and directories ('.' in front)
    
    f) ls -lhS --> sort by file size and largest come first, not real size of directory (real size should be check with du command)
    
    g) du command to check the real size of directory
        du -sh /etc --> show 17M

    h) ls -l -X --> sort by extension
        ls -l -X /etc

    i) ls --hide=*.conf /etc --> hide files with .conf

    j) ls -lR --> list the files and directories recursively

    k) \ls -l --> run ls command without alias 
        when we run: ls -l actually we run ls --color=auto -l (using alias)

    g) ls */ --> listing only directories in current directory
        ls -ld /etc/*/ --> listing only directories inside of directory '/etc'

5) understanding file timestamps: atime, mtime, ctime (stat, touch, date)
    atime: access timestamp --> the last time the files was read (ls -lu), someone open the 
content of the file
    mtime: modified timestamp --> the last time the file content was modified (ls -l, ls -lt), someone use text
editor to change the content of the file
    ctime: changed timestamp --> the last time the file metadata was changed (ls -lc), changing the file permission
or file owner

    a) To view these timestamp, we can use the command 'stat'
        stat /etc/passwd

        ls -lu --> view atime
        ls -lt --> view mtime
        ls -lc --> view ctime

    b) To view modification time with details to the level of seconds, we can combine
'-l' and '--full-time'
        ls -l --full-time

    c) change timestamp on a file, use 'touch' command
        touch linux.txt --> create new file with timestamp
        touch linux.txt --> timestamp all updated

        touch -a linux.txt --> change the atime, but ctime also changed since meta changed
        touch -m linux.txt --> change the mtime, but ctime also changed

        touch -m -t yyyymmddhhmm.ss linux.txt --> change mtime of file to a specific time with (-m -t)
            for ex: touch -m -t 201812301530.45 linux.txt

        touch -d "2010-10-31 15:45:30" linux.txt --> change atime and mtime at the same time

        touch linux.txt -r ubuntu.txt --> get timestamp of linux.txt and put to ubuntu.txt

    Note:
        + date --> view current date
        + date --> view current date by utc

6) sorting files by timestamp
    ls -lt --> view the files and sort by modification time
    ls -ltu --> show and sort by access time
    ls -lu --> show access time and sort by name
    ls -lu -r --> show access time, sort by name but reversely

    ls -ltur or ls -ltu --reverse --> show atime, sort by atime reversely

7) file types in linux
    .log --> log file
    .conf --> configuration file

    a) use 'file' command to determine what type of file by examining its content
        file Linux.jpeg --> JPEG image data 
        mv ./Linux.jpeg ./Linux.png --> rename with mv command
        file ./Linux.png --> still JPEG image data (file command based on content)

    b) how to view to recognize what type of file
        ls -l /etc
            -: normal file
            d: directory
            l: symbolic link (like a shortcut)

        ls -l /dev/sda1
            b: block device (data in blocks: hdd, sdd, usb)

        ls -l /dev
            c: char device (data as stream of characters/bytes: keyboard, terminal, serial port)

        ls -l /run
            s: file socket, process-to-process communication
            p: name piped file, process-to-process data stream

    c) how to recognize a file or a direction, we can use command ls with '-F'
        ls -F --> classify, if you see 'Downloads/' is directory with '/' after the name
        ls -F /etc --> localtime@, @ is symlink
        ls -lF /run 
            --> snapd.socket=, = is socket file
            --> initctl|, | is pipe files
        ls -lF /usr/bin --> see 'ps*', * stand for executable file

    d) can use 'file' to check file type
        file /etc --> directory
        file /etc/passwd --> ASCII text, normal file
        file /etc/vtrgb --> symbolic link
        file /run/* --> show all the file type in directory /run
            example: file /etc/*

8) Viewing files

            ctrl + f, ctrl + b --> up or down windows screen

    c) Viewing files with tail, head, watch

10) Copying Files and directories

was existed, if not it will create new file 
    cp /etc/group ./users.txt --> run copy here again, and users.txt content will be replaced
with new content since it's already existed
        -v: verbose, when we want to show details information
        -i: prompt, when we want it asks before doing something

    cp learning_linux.txt logs users.txt first/ --> copy 3 files into first directory
    cp -i learning_linux.txt logs users.txt first/ --> do the samething with prompting, if already existed

    sudo cp -r /etc/ ~/Desktop --> copy all directory with everything inside to another directory
        -r: recursive

    sudo cp users.txt u.txt --> copy file with root (here is sudo priviledge) to another file, the
owner and group of the file 'u.txt' become 'root root'
        note: the user run the 'cp' command become the file's owner

    sudo cp -p users.txt u1.txt --> in this case, we can 'preserve' the file permission, owner, etc
with '-p'
        note: '-p' --> preserve

11) Moving and Renaming Files and Directories 
    a) moving multiple files
        mv c.txt dir1/a.txt dir1/b.txt dir1/dir2/ --> moving multiple files to dir1/dir2/
    
    b) moving with wildcard
        mv dir1/dir2/*.txt dir1/ --> moving with wildcard * for all txt files
    
    c) moving with options: -i: prompt, -n: not overwrite, -u: update
        mv -i dir1/dir2/a.txt dir1/ --> using the i to prompt when inside dir1 also have file
'a.txt', when move like that it will overwrite the content of dir1/a.txt
            Note: -i: using the prompting interactive to check before overwriting

        mv -n dir1/dir2/a.txt dir1/ --> using '-n' or no-clobber, not overwrite the existing file,
so in this case a.txt will not be moved

        touch dir1/dir2/b.txt --> create b.txt inside dir2, inside dir1 also has 'b.txt'
        mv -u dir1/b.txt dir1/dir2 --> it will not move dir1/b.txt to dir1/dir2 since we use
'-u' or update option, it just moves when destination not exists or the source is newer than destination,
in this case it will be older

    d) rename file
        mv dir1/a.txt dir1/abc.txt --> rename file a.txt to abc.txt

    e) rename directory
        mv dir1/ dir10 --> rename directory dir1 to dir10

    f) move and rename at the same time 
        mv dir10/c.txt dir10/dir2/cc.txt --> move c.txt inside dir10 to dir2 with name cc.txt

12) Removing files and directories (rm, shred)
    a) removing files (-i: interactive, -v: verbose)
        rm dir10/abc.txt dir10/dir2/a.txt --> files remove immediately without prompting
        rm -i dir10/dir2/b.txt --> remove file 'b.txt' with prompting question, y to remove
        rm -v dir10/b.txt --> remove file 'b.txt' with detailed what file removed

    b) removing directories
        rm -r dir10/ --> remove directory dir10 with '-r: recursive' option
    
    c) removing with -f: force option
        rm -rf Music/ Pictures/ --> remove directories with force option

    d) using 'shred' to overwrite the file many times before delete it to make sure it will not
be recovered
        shred -vu -n 100 passwd --> -v: verbose, -u: removing after overwriting, -n: overwrite number times
(default will be 3), the file will be overwritten with random content before removing

14) Command Redirection
    a) redirect with >
        ls -l > ls.txt --> redirect output of ls -l to file with name 'ls.txt'
        ifconfig > ls.txt --> this time the content of ls.txt will be overwritten by content of command 'ifconfig'
            note: > will create new file if not exists, but overwrite if exists

    b) append with >>
        ls -l > output.txt --> redirect like normal
        ifconfig >> output.txt --> this time do not overwrite but append with '>>', so 'output.txt'
will have the content of ls -l and also the ifconfig

    c) standard error 2
        tail -n 3 /etc/shadow 2> error.txt --> redirect error output to file 'error.txt'
with standard stream 2 for error
        tail -n 3 /etc/shadow 2>> error.txt --> this time append the error one more
time with 2>>
        dsfa 2>> error.txt --> continue to append error to error.txt

        tail -n 2 /etc/passwd /etc/shadow > output.txt 2> error.txt --> redirect 
normal output to output.txt and error to error.txt at the same time

    d) redirect standard output and standard error to the same file, redirect standard
output the file and redirect standard error to standard output
        tail -n 2 /etc/passwd /etc/shadow > output.txt 2>&1 --> after this command, both
content of /etc/passwd and error go to output.txt

    e) combine pipe and redirect
        ifconfig | grep ether > mac.txt --> search the line contains 'ether' in ifconfig command 
save to a file called 'mac.txt'

    f) using cut
        ifconfig | grep ether | cut -d " " -f 10 --> cut with -d delimeter " " and get -f field 10
        ifconfig | grep ether | cut -d " " -f 10 > mac.txt --> redirect to mac.txt with only 'mac address number'

        cat /etc/passwd | cut -d ":" -f 1 --> get only username on /etc/passwd file
        cat /etc/passwd | cut -d ":" -f 3 --> get user id 
    
    g) whatif we want to store and output to terminal at the same time (tee command)
        ifconfig | grep ether | tee mac.txt --> redirect output to mac.txt and show output to terminal
    at the same time 
            note: tee command overwrite the file by default

        w | tee -a mac.txt --> use option '-a' with tee to append the content to the file
        
        uname -a | tee mac.txt kernel.txt --> write to multiple files at the same time

15) Finding files and Directories
    a) how to tell where the executable for a command is located, using 'which'
        which rm --> /usr/bin/rm

        which -a find --> showed all of version of executable commands with -a
            here is /usr/bin/find and /bin/find, they are hardlinks (2 pointers) or different names
for the same file
    
        which pwd rm find less ls --> we can search many executable commands at the same time

    b) search files and directories with plocate (faster since it based on local database), but
give less result
        sudo updatedb --> update the database of plocate command 
        
        plocate passwords --> locate paths with name 'passwords'
        plocate rrides --> locate paths has 'rrides' inside absoluate paths

        plocate -b rrides --> locate paths has 'rrides' only in base name (file name), not the whole path

        plocate *passwd* --> locate paths has anything before and after 'passwd'

        plocate -r '/passwd$' --> search all paths which ending in /passwd 
            $: make sure it is final part of the path

        touch myfile123x --> create new file with name 'myfile123x'
        plocate myfile123x --> have no result since it is not updated in database
        sudo updatedb --> update local database of locate
        plocate myfile123x --> this time it shows the result

        rm myfile123x --> remove this file 
        plocate myfile123x --> still find it, that means give us a false result 
        plocate -e myfile123 --> this command will check this file really exists
            (-e: existing)

        plocate Rainshadow --> nothing was found
        plocate -i Rainshadow --> have result with -i: ignore case insensitive
