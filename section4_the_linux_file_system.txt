5) understanding file timestamps: atime, mtime, ctime (stat, touch, date)
    atime: access timestamp --> the last time the files was read (ls -lu), someone open the 
content of the file
    mtime: modified timestamp --> the last time the file content was modified (ls -l, ls -lt), someone use text
editor to change the content of the file
    ctime: changed timestamp --> the last time the file metadata was changed (ls -lc), changing the file permission
or file owner

    a) To view these timestamp, we can use the command 'stat'
        stat /etc/passwd

        ls -lu --> view atime
        ls -lt --> view mtime
        ls -lc --> view ctime

    b) To view modification time with details to the level of seconds, we can combine
'-l' and '--full-time'
        ls -l --full-time

    c) change timestamp on a file, use 'touch' command
        touch linux.txt --> create new file with timestamp
        touch linux.txt --> timestamp all updated

        touch -a linux.txt --> change the atime, but ctime also changed since meta changed
        touch -m linux.txt --> change the mtime, but ctime also changed

        touch -m -t yyyymmddhhmm.ss linux.txt --> change mtime of file to a specific time with (-m -t)
            for ex: touch -m -t 201812301530.45 linux.txt

        touch -d "2010-10-31 15:45:30" linux.txt --> change atime and mtime at the same time

        touch linux.txt -r ubuntu.txt --> get timestamp of linux.txt and put to ubuntu.txt

    Note:
        + date --> view current date
        + date --> view current date by utc

14) Command Redirection
    a) redirect with >
        ls -l > ls.txt --> redirect output of ls -l to file with name 'ls.txt'
        ifconfig > ls.txt --> this time the content of ls.txt will be overwritten by content of command 'ifconfig'
            note: > will create new file if not exists, but overwrite if exists

    b) append with >>
        ls -l > output.txt --> redirect like normal
        ifconfig >> output.txt --> this time do not overwrite but append with '>>', so 'output.txt'
will have the content of ls -l and also the ifconfig

    c) standard error 2
        tail -n 3 /etc/shadow 2> error.txt --> redirect error output to file 'error.txt'
with standard stream 2 for error
        tail -n 3 /etc/shadow 2>> error.txt --> this time append the error one more
time with 2>>
        dsfa 2>> error.txt --> continue to append error to error.txt

        tail -n 2 /etc/passwd /etc/shadow > output.txt 2> error.txt --> redirect 
normal output to output.txt and error to error.txt at the same time

    d) redirect standard output and standard error to the same file, redirect standard
output the file and redirect standard error to standard output
        tail -n 2 /etc/passwd /etc/shadow > output.txt 2>&1 --> after this command, both
content of /etc/passwd and error go to output.txt

    e) combine pipe and redirect
        ifconfig | grep ether > mac.txt --> search the line contains 'ether' in ifconfig command 
save to a file called 'mac.txt'

    f) using cut
        ifconfig | grep ether | cut -d " " -f 10 --> cut with -d delimeter " " and get -f field 10
        ifconfig | grep ether | cut -d " " -f 10 > mac.txt --> redirect to mac.txt with only 'mac address number'

        cat /etc/passwd | cut -d ":" -f 1 --> get only username on /etc/passwd file
        cat /etc/passwd | cut -d ":" -f 3 --> get user id 
    
    g) whatif we want to store and output to terminal at the same time (tee command)
        ifconfig | grep ether | tee mac.txt --> redirect output to mac.txt and show output to terminal
    at the same time 
            note: tee command overwrite the file by default

        w | tee -a mac.txt --> use option '-a' with tee to append the content to the file
        
        uname -a | tee mac.txt kernel.txt --> write to multiple files at the same time

16) Finding Files and Directories (with find command)
    a) search file by name
        find . -name todo.txt --> search file by name with (-name) at current directory

    b) search file by name but case insensitive
        find . -iname toDo.txt --> same as above but -iname with case insensitive, still found the file 'todo.txt'

    c) search file by name with wildcard
        find . -name "todo*" --> search file by name with wildcard (*)
        (we can write like this: find . -name todo* but above better)

        find . -name "*rep*" --> search file by name with contains 'rep'

    d) search file by name and delete when found (dangerous)
        find . -name todo.txt -delete --> search and delete at the same time, be careful

    e) search file by name with sudo when need permission
        sudo find /etc/ -name passwd --> search file name 'passwd' by root priviledge

    f) search file by name and list file afterward
        sudo find /etc -name passwd -ls --> we can execute 'ls' with find by using option '-ls'

    g) search file by type
        find /etc -type d --> search all directories in /etc recursively (in this case could be list all directories in /etc)

        find /etc -type d -maxdepth 2 -perm 755 | wc -l --> search directories in /etc with maximum level is
2 and with permission is 755 and count how many

    h) search using multiple criteria such as type and size
        sudo find /var -type f -size 100k -ls --> search in /var with type is 'file'
and size is 100k and after that list those files

        sudo find /var -type f -size +10M -ls --> use '+' or '-' to show greater
than or smaller than the size we want, here is greater than 10 megabytes

        sudo find /var -type f -size +10k -ls --> search for size less than 10 kilobytes

        sudo find /var -type f -size +5M -size -10M --> search for size larger than 5 megabytes
and less than 10 megabytes

    i) search file by mtime
        find /var -type f -mtime 0 -ls --> search files modified by the last
24 hours, 0 here mean < 24h, 1 mean 24 - <48h, 2 mean 72 - <96h, cycle of 24 hours

        find /var -type f -mtime 1 -ls --> search files modified by 1-2 days ago 
(from 24 to less than 48 hour)

    j) search file by atime
        find /var -type f -atime +1 -ls --> search files were accessed at least 
1-2 days ago

    k) search file by mmin
        find /var -type f -mmin -60 --> search file was modified less than 60 minutes
        find /var -type f -mmin 60 --> modified by exactly 60 mins ago, so no result found

    l) search file by user
        sudo find /var -type f -user gdm -ls --> search files belong to gdm user

    m) search file using negate (not)
        sudo find /var -type f -not -group root -ls --> search files not belong to
'root' group

        NOTE:
            -mtime 0	Less than 24 hours old
            -mtime 1	24–<48 hours old
            -mtime 2	48–<72 hours old
            -mtime 3	72–<96 hours old
            -mtime -1	Less than 24 hours old
            -mtime -2	Less than 48 hours old
            -mtime -3	Less than 72 hours old
            -mtime +0	More than 24 hours old
            -mtime +1	More than 48 hours old
            -mtime +2	More than 72 hours old
            -mtime +3	More than 96 hours old

24) Compressing and Archiving Files and Directories
    archiving is the process of put files into bigger file (not compress), 10 files 100KB -> 1 file 1000KB
    compressing is the process of compressing files into a single with lower file size

    tar: will create the archive, not compress them, but with option it will include compression algorithm
        -c: create an archive 
        -x: extract archive
        -t: display contents of archive

    a) Compress into gzip file 
        sudo tar -czvf etc.tar.gz /etc --> compress directory into gz file
            (c: archive, z: compress archive using gzip, f: specify the file name, need file name right after -f)

    b) Compress into bzip file
        sudo tar -cjvf etc.tar.bz2 /etc --> compress directory into bz2 file (smaller than gz but the process will be slower)
            (j: bz2)
    
    c) Compress multiple files 
        tar -czvf archive.tar.gz /etc/passwd /etc/group /var/log/dmesg --> compress multiple files into a single compressed file

    d) Compress multiple files and directories
        sudo tar -czvf archive.tar.gz /etc/passwd /etc/group /var/log/dmesg --> compress multiple files and directories into compressed file

    e) Compress with exclude files with extension such as mkv, config and cache file =
        tar --exclude="*.mkv" --exclude='.config' --exclude='.cache' -czvf myhome.tar.gz ~
    
    f) Extract tar file
        tar -xzvf etc.tar.gz --> extract gz file
        tar -xjvf etc.tar.bz2 -C /my_backup --> extract bz2 file into different directory with -C option

    g) View the content of compress file, not extract it, could filter to look for the file what we need
        tar -tf etc.tar.bz2 | grep sshd_config --> use option -t to view files/paths of compress file, 
    not searching content of each files 

    h) Compress file with current date using trick $(date +%F)
        sudo tar -cjvf etc-$(date +%F).tar.bz2 /etc --> compress file with date to store backup

    i) Extract .xz file 
        tar -xvf ./coreutils-9.11.tar.xz

    j) Some other commands to compress and extracts
        gzip --> compress into gz archive
        gunzip --> extract the gz archive
        bzip2 --> compress into bz2 archive
        bunzip2 --> extract the bz2 archive
