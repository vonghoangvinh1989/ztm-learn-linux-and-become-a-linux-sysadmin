4) the ls command in depth
    a) ls -1 /etc --> display in one line with '-1'
    
    b) ls -l /etc --> display long listing with '-l'
        drwxr-xr-x  2 root                 root                  4096 Jul 22 20:38 vim
        lrwxrwxrwx  1 root                 root                    23 Jun  4  2025 vtrgb -> /etc/alternatives/vtrgb
        -rw-r--r--  1 root                 root                  4942 Oct  2  2025 wgetrc
  
        'd' in front --> directory
        'l' in front --> symbolic link, like a shortcut
        '-' in front --> file
        'rwxrwxrwx' --> indicate permission of "owner, group owner and others"
        '2' --> the number of hard links
        'root root' --> owner and group owner
        '4096" --> size
        'Jul 22 20:38 vim' --> modification time and file name

    c) ls -ld /etc --> display long listing with only directory, not list the content of directory '-d'
    
    d) ls -lh /etc --> show file size in readable format
    
    e) ls -la ~ --> show all, includes hidden files and directories ('.' in front)
    
    f) ls -lhS --> sort by file size and largest come first, not real size of directory (real size should be check with du command)
    
    g) du command to check the real size of directory
        du -sh /etc --> show 17M

    h) ls -l -X --> sort by extension
        ls -l -X /etc

    i) ls --hide=*.conf /etc --> hide files with .conf

    j) ls -lR --> list the files and directories recursively

    k) \ls -l --> run ls command without alias 
        when we run: ls -l actually we run ls --color=auto -l (using alias)

5) understanding file timestamps: atime, mtime, ctime (stat, touch, date)
    atime: access timestamp --> the last time the files was read (ls -lu), someone open the 
content of the file
    mtime: modified timestamp --> the last time the file content was modified (ls -l, ls -lt), someone use text
editor to change the content of the file
    ctime: changed timestamp --> the last time the file metadata was changed (ls -lc), changing the file permission
or file owner

    a) To view these timestamp, we can use the command 'stat'
        stat /etc/passwd

        ls -lu --> view atime
        ls -lt --> view mtime
        ls -lc --> view ctime

    b) To view modification time with details to the level of seconds, we can combine
'-l' and '--full-time'
        ls -l --full-time

    c) change timestamp on a file, use 'touch' command
        touch linux.txt --> create new file with timestamp
        touch linux.txt --> timestamp all updated

        touch -a linux.txt --> change the atime, but ctime also changed since meta changed
        touch -m linux.txt --> change the mtime, but ctime also changed

        touch -m -t yyyymmddhhmm.ss linux.txt --> change mtime of file to a specific time with (-m -t)
            for ex: touch -m -t 201812301530.45 linux.txt

        touch -d "2010-10-31 15:45:30" linux.txt --> change atime and mtime at the same time

        touch linux.txt -r ubuntu.txt --> get timestamp of linux.txt and put to ubuntu.txt

    Note:
        + date --> view current date
        + date --> view current date by utc

6) sorting files by timestamp
    ls -lt --> view the files and sort by modification time
    ls -ltu --> show and sort by access time
    ls -lu --> show access time and sort by name
    ls -lu -r --> show access time, sort by name but reversely

    ls -ltur or ls -ltu --reverse --> show atime, sort by atime reversely

7) file types in linux
    .log --> log file
    .conf --> configuration file

    a) use 'file' command to determine what type of file by examining its content
        file Linux.jpeg --> JPEG image data 
        mv ./Linux.jpeg ./Linux.png --> rename with mv command
        file ./Linux.png --> still JPEG image data (file command based on content)

    b) how to view to recognize what type of file
        ls -l /etc
            -: normal file
            d: directory
            l: symbolic link (like a shortcut)

        ls -l /dev/sda1
            b: block device (data in blocks: hdd, sdd, usb)

        ls -l /dev
            c: char device (data as stream of characters/bytes: keyboard, terminal, serial port)

        ls -l /run
            s: file socket, process-to-process communication
            p: name piped file, process-to-process data stream

    c) how to recognize a file or a direction, we can use command ls with '-F'
        ls -F --> classify, if you see 'Downloads/' is directory with '/' after the name
        ls -F /etc --> localtime@, @ is symlink
        ls -lF /run 
            --> snapd.socket=, = is socket file
            --> initctl|, | is pipe files
        ls -lF /usr/bin --> see 'ps*', * stand for executable file

    d) can use 'file' to check file type
        file /etc --> directory
        file /etc/passwd --> ASCII text, normal file
        file /etc/vtrgb --> symbolic link
        file /run/* --> show all the file type in directory /run
            example: file /etc/*

8) Viewing files
    a) Viewing files with cat command
        cat /var/log/auth.log --> view content of a file by cat
        cat /etc/passwd /etc/group --> view 2 files at the same time
        cat -n /etc/passwd --> view the file with line number (option -n)

        cat /etc/hosts /etc/host.conf > my_host.txt --> concatenate contents of 2 file into 
a new file called my_host.txt
            > : output redirection

    b) Viewing files with less, more 
        less /var/log/dmesg --> we call it pager, moving around with options
            h --> help
            ctrl + f, ctrl + b --> up or down windows screen
            g --> to beginning
            G --> to end
            /term --> for search when stand at the beginning, match up and down with 'n' and 'N'
            ?term --> for search when at the end, match up and down with 'n' and 'N'
    
    c) Viewing files with tail, head, watch
        + TAIL
        tail /etc/passwd --> view the last 10 lines of file (in default)
        tail -n 2 /etc/group --> view the last customed line of file (here is 2 with -n)
        tail -n +20 /var/log/syslog --> view from line 20 to the end
        
        tail -f /var/log/auth.log --> view the log with updating content of file, the content will write into it
            /var/log/auth.log --> where to view authentication logging like login, logout
        
        + HEAD
        head /etc/passwd --> view the first 10 lines of file
        head -n 3 /etc/group (head -3 /etc/group) --> view the first 3 line

        + WATCH
        watch ls --> run the 'ls' command repeatively until unterrupting with 'ctrl + c'
        watch -n 3 -d ls -l --> run the 'ls -l' command repeatively with options
            -n 3: every 3 seconds
            -d: highlight differences

        watch -n 1 ifconfig --> watch the traffic of network each 1 second repeatedly
